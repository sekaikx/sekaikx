Work

Lifeline

Desktop app · Rust, Tauri, ONNX · Source on GitHub

After a flood or an earthquake, planners have to decide how to reach villages the roads no longer serve. Lifeline loads real terrain, roads and the wind forecast for any area, compares truck, drone and airdrop for every request, and writes a schedule a planner can check line by line.

It also finds flooded roads in Sentinel-2 satellite images with a small model I trained, which runs on the laptop through ONNX.

How a project runs

Price and scope are agreed in writing before any code is written.

  1. Brief

    You send a few lines about what you need. I reply with questions or a first idea of how I’d build it.

  2. Scope and price

    I write down what’s included, what isn’t and the delivery date, with a fixed price.

  3. Build

    You get working versions as I go, so you can react to the real thing while changes are cheap.

  4. Hand-over

    You receive the repository, build instructions and notes on how it works.

FAQ

How is a project priced?

After we’ve talked it through, I write down the scope and quote a fixed price for it. You decide before any work starts.

Do I own the code?

Yes. At hand-over you get the repository, the build setup and notes on how it works. You can keep it, change it or give it to another developer.

I’m not technical. Can we still work together?

Yes. Describe what you want in your own words. I’ll ask questions, then show you working versions as I go.

Can you take over an existing project?

Often. I read the code first, then tell you whether fixing, extending or rebuilding makes more sense, and why.

Machine learning · Python, PyTorch

Flood mapping from satellite images

A small U-Net trained on hand-labelled Sentinel-2 scenes, exported to ONNX to run on a laptop. It holds up in regions it never saw: 0.81 IoU on Bolivia against 0.61 for the water index.

How working together goes

No agency layers and no surprises. You talk to the person writing the code.

  1. Tell me what you need

    A few lines by email is enough. I reply with questions, or a first idea of how I’d build it.

  2. Agree scope and price

    What’s in, what’s out and when it’s done, written down before any work starts.

  3. Build in the open

    You get working builds early and often, not just status reports, so changes are cheap.

  4. Hand over everything

    Source code, notes on how it works and how to run it. You own all of it.

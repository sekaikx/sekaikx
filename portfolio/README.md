# Portfolio

The site behind [sekaikx.vercel.app](https://sekaikx.vercel.app). It replaces the old Sillage template: same idea of one static page with no build step, but with real content and a design of its own.

Open `index.html` through any static server (`python3 -m http.server 8090` in this folder) to work on it.

## Deploying on Vercel

Import the `sekaikx/sekaikx` repository in Vercel and deploy. `vercel.json` at the repository root does the rest: it serves this folder and, on every deploy, refreshes the GitHub contribution calendar behind the "A year of commits" section. If GitHub can't be reached during the build, the section simply stays hidden.

## Files

```
index.html                 the page
assets/css/site.css        all styles; tokens at the top
assets/js/site.js          hero map overlay (routes, labels, scale bar) and the contribution profile
assets/map/                relief.webp, lines.svg and overlay.js, generated by tools/map/build_map.py
assets/lifeline/           screenshots from the Lifeline repository
assets/data/contributions.js   written by tools/contributions.mjs at deploy time
tools/map/build_map.py     builds the map from AWS Terrain Tiles and an OpenStreetMap export
tools/og-image.mjs         renders assets/og.jpg, the social preview
tools/contributions.mjs    fetches the public contribution calendar (from Sillage)
```

To rebuild the map, download the terrarium tiles for zoom 12, x 3009–3012, y 1715–1718 from `https://s3.amazonaws.com/elevation-tiles-prod/terrarium/12/{x}/{y}.png` into one folder, export roads (`highway` primary to track) and places for the bounding box `27.90,84.50,28.05,84.75` from Overpass as JSON, then run `python3 tools/map/build_map.py <tiles folder> <export.json>` (needs `numpy`, `pillow` and `contourpy`).

## Design notes

The page is a field map, because Lifeline is about terrain. Keep new work inside these rules so it stays one piece.

- **Colour.** Map paper `#f3f5f1`, print ink `#1e2326`, contour brown `#8a6f52`, water blue `#2f6daa`, and aeronautical-chart magenta `#a3195b` for routes, links and the one primary button per section. Nothing else gets the magenta.
- **Type.** Barlow only, in three widths: Semi Condensed for headings, Condensed for map labels and legends, regular for text. Sentence case everywhere. Monospace only for real terminal output.
- **Motion.** One moment: the routes draw themselves in when the page loads. Nothing else animates on its own, and reduced motion turns it off.
- **Structure.** Rules and boxes only where a map would have them: the title cartouche, the legend, table headers. No card grids, no numbered sections, no labels above headings.
